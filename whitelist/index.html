白名单申请与查询

LongerMC 使用 Minecraft 原版白名单。本系统只负责收集申请、邮箱验证与人工审核记录， 最终是否加入原版白名单由管理员在服务器上手动执行。

申请白名单

填写邮箱、游戏 ID 与联系方式（QQ / Discord 至少一项），完成邮箱验证码与人机验证后提交。

查询申请状态

输入邮箱，通过邮箱验证码验证后自助查看审核进度，无需等待人工回复。

修改白名单信息

修改 QQ / Discord / 游戏 ID 或绑定邮箱，也可补充之前未填的联系方式，需填写修改理由并人工审核。

前往修改 →

进服前须知

申请前请确认以下条件，审核员会逐项人工核验：

  • QQ 号已加入或已申请加入服务器 QQ 交流群（QQ 等级需满 15 级才可进群），且该 QQ 号尚未申请过白名单；
  • 或 Discord 已加入 / 已申请加入 LongerMC Discord 服务器；
  • 游戏 ID（IGN）填写准确，只能包含字母、数字与下划线，长度 3-16 位；
  • 邮箱需能正常接收验证码，用于申请、查询与修改的身份校验。

说明：本系统内的审核记录独立于 Minecraft 服务器。审核通过只代表申请已获批准， 管理员还需在服务器执行 whitelist add <IGN> 后才能真正进服。
