MODIFY

修改白名单信息

可修改 QQ、Discord 或游戏 ID，也可以补充之前未填的联系方式。修改需填写理由， 提交后进入人工审核；审核通过前当前白名单信息保持不变。

1 · 身份验证

需要邮箱（必填，接收 6 位验证码）+ QQ / Discord / 游戏 ID 三选一做辅助验证。 系统会核对这两项是否与你的申请记录一致。用哪一项验证，本次就不能改哪一项； 要改某一项，请改用另外两项之一来验证。

选择你当前仍记得、且已绑定在申请记录上的那一项。

请填写当前生效的游戏 ID。

2 · 填写修改内容

只填写需要变更的项，留空表示不修改。修改理由必填（至少 5 个字）。QQ 与 Discord 不能同时为空，如需清空某一项请勾选对应的「清空」。

修改游戏 ID 后，管理员需要到原版服务器手动替换白名单条目。

当前邮箱仍可正常收信时才能在线更换：新邮箱必须独立完成一次验证码验证。 如果当前邮箱已经无法使用（停用、丢失、收不到信），在线流程无法验证你的身份， 请改用页面底部的全人工通道。

更换后，状态查询与后续通知都将使用新邮箱。

修改申请已提交

修改编号 ，状态为「待人工审核」。 审核通过前当前白名单信息保持不变，审核结果会通过邮件通知你。
